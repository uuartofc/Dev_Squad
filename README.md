Um squad de agentes de IA projetado para guiar o ciclo de vida do seu software desde a concepção de ideias até o deploy verificado. O pacote instala automaticamente especialistas, *skills*, *workflows*, regras e scripts de controle de qualidade na estrutura do seu projeto.

> **Pré-requisitos:** Node.js 18+ (obrigatório). Os scripts de auditoria também exigem Python 3.9+.

---

## 🚀 Instalação e Uso Rápido

### Usando o NPM (Recomendado)

Execute o comando abaixo **na raiz do projeto** que receberá o squad:

```bash
npx @uuartofc/squad-dev-team
